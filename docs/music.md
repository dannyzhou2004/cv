# 背景音乐：从"本地 MP3"改为"B 站官方播放器嵌入"

## 结论先行

原来的做法是：把视频音轨转成 `bgm.mp3` 放进 `public/audio/`，用原生 `<audio>` 播放。
现在改为：**不在仓库里放任何音频文件**，点击页头按钮后挂载 B 站官方播放器
（`https://player.bilibili.com/player.html?bvid=…`），音源始终由 B 站提供，原视频链接同时放在页面上。

这样处理的收益：

| 维度 | 本地 MP3（旧） | B 站嵌入（现） |
|---|---|---|
| 仓库/站点体积 | +3.43 MB | **0**（iframe 点击后才请求） |
| 版权形态 | 复制音频并公开分发 | 官方播放器"分享"，音频不出 B 站 |
| 视频失效 | 无影响（文件在本地） | 播放器显示错误页，换 BV 即可 |
| 后台播放体验 | 无画面、可淡入、可循环 | 有播放器画面，自动播放可能被拦，需点播放器 |
| 可控性 | 完全可控（音量/循环） | 受 B 站播放器与浏览器策略限制 |

**代价要说清楚**：这不是"真·背景音乐"——B 站播放器自带画面和控件，浏览器还可能拦截它的自动播放，访客可能要再点一次播放键。要"点一下就无缝在后台响"，只能自己托管已授权音频。

## 原始素材

- 本地源文件：`43403250064-1-192.mp4`（Bilibili 下载，H.264 590×1280、4:59.38；音轨 AAC 44.1 kHz 立体声 72 kb/s；封面为 RALPH LAUREN 标志）
- 文件名里的 `43403250064` 是 B 站的 **cid（分P 流 id）**。已确认它对应 **`BV1ta4J6TET9`**（《【拉夫劳伦斯】纯音乐超长版。》，UP @行为准责，300 s，纯音乐无人声）——B 站 API 返回的 cid 与文件名完全一致。
- 之前转码好的 `bgm.mp3`（96 kb/s、-18 LUFS、3.43 MB）已从仓库移除；如果未来要改回本地播放，可按原参数重新生成（ffmpeg 两遍 loudnorm + 1.5 s/2.5 s 淡变）。

## 如何填入视频

两份数据文件里填同一组值（当前已填好）：

```ts
// src/data/resume.en.ts / resume.zh.ts
music: {
  bvid: 'BV1ta4J6TET9',
  url: 'https://www.bilibili.com/video/BV1ta4J6TET9/',
  title: '《拉夫劳伦进行曲》纯音乐',   // 英文文件里是 "Ralph Lauren march — instrumental"
  credit: 'B 站 · @行为准责',              // 可选署名
}
```

- `bvid` 为空 → 页头不渲染音乐按钮，不会留下死按钮。
- 只支持单 P 视频；分 P 可在 URL 后加 `&page=2`（当前模板固定 `page=1`，需要时再扩展）。
- 视频若开启"仅充电/付费/地区限制"，嵌入播放器可能无法播放。

## 交互与实现

- 按钮在页头右侧（equalizer 图标），`aria-expanded` / `aria-controls` 同步状态。
- 面板里 is **按需创建** iframe：首次展开才注入，首屏 0 请求；关闭 / Esc / 点击面板外部时移除 iframe（跨域无法调 `pause()`，移除是唯一可靠的停止方式）。
- 面板包含：标题、16:9 播放器、提示文案、原视频链接（`target="_blank" rel="noopener noreferrer"`）。
- 移动端面板宽度 `min(20rem, 100vw - 1.5rem)`，不会撑出横向滚动。
