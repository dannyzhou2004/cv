## 来源与处理

- 源：B 站视频（`cid=43403250064`，页面 `BV1ta4J6TET9`）的**音轨**；页面不出现任何 B 站链接或播放器。
- 处理：提取音轨 → 跳过前 10 s → `afade` 0.25 s / 2.5 s → `loudnorm I=-18:TP=-1.5:LRA=11` → `libmp3lame 96k`。
- 重新生成的命令（ffmpeg 在 PATH 中即可）：

```bash
ffmpeg -y -i source.mp4 -vn -ss 10 \
  -af "afade=t=in:st=0:d=0.25,afade=t=out:st=286.87:d=2.5,loudnorm=I=-18:TP=-1.5:LRA=11" \
  -ar 44100 -ac 2 -c:a libmp3lame -b:a 96k public/audio/bgm.mp3
```

## 播放策略（进站自动播放 + 4 s 渐入）

1. 页面加载约 **0.9 s** 后尝试 `audio.play()`；音量从 **0** 用 **4 s** 按平方曲线升到 **0.294**（比原来的 0.42 低 30%，前两秒几乎听不见）。
2. 浏览器若拦截**有声**自动播放（Chrome/Safari 对新访客默认如此）：
   - 自动降级为**静音自动播放**，音轨已经在走；
   - 页头出现「点击开启声音」提示；
   - **滚动滚轮 / 手指滑动 / 点击 / 按键**任一动作都会取消静音，并同样从 0 用 4 s 淡入。
3. 若连静音自动播放都被拒绝（少数环境），则等第一次**点击或按键**直接开始，并同样淡入。
   （按 HTML 规范，滚动/滚轮不算"用户激活"，这种环境下单靠滚轮无法启动声音。）
4. **循环**：不再用原生 `loop`。末尾还剩 3 s 时开始淡出到 0，`ended` 后回到 0 秒、音量归零并重新播放，再用 4 s 淡入——接缝处不会有突兀的音量跳变。
5. 页头四分音符按钮：随时暂停/继续；暂停有 0.9 s 淡出，继续则重新从 0 用 4 s 淡入；一旦手动暂停，滚动不会再把音乐拉起来。

> 现实边界：浏览器不允许"无交互、有声"自动播放，这是平台规则，网页端无法绕过。最理想的效果是——**回访者直接听到淡入，首次访客看到静音播放 + 一句提示，随便点一下就淡入**。

## 性能代价

为了让音乐"进来就响"，`<audio preload="auto">` 会在首屏就下载这 3.31 MB；整站产物约 3.88 MB。如果以后更在意首屏速度，可以降到 64 kb/s（≈2.3 MB）、改成点击后才加载，或者接受"静音开场、点一下才播"。
